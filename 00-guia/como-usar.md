# Como usar o acervo

## Resumo
Guia rápido de consulta e contribuição. As regras completas estão em `REGRAS.md`.

## Consultar
1. Abra `INDICE.md`.
2. Para um sistema, vá a `02-sistemas/<sistema>/README.md`.
3. Para entender *por que* algo é assim, veja os ADRs linkados em `relacionados`.

## Contribuir
| Quero... | Modelo | Destino |
|---|---|---|
| Documentar um sistema | `_modelos/SISTEMA.md` | `02-sistemas/<sistema>/README.md` |
| Registrar uma decisão | `_modelos/DECISAO.md` | `03-decisoes/ADR-NNNN-titulo.md` |
| Descrever um processo | `_modelos/PROCESSO.md` | `05-processos/<processo>.md` |
| Resumir material externo | `_modelos/REFERENCIA.md` | `06-referencias/<assunto>.md` |
