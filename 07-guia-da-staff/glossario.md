# Glossário da Staff

## Resumo
Palavras do jogo explicadas de forma simples. Ordem alfabética.

| Termo | O que significa |
|---|---|
| Carga (de manutenção) | "Combustível" que mantém arma ou armadura de um material funcionando 100%. Vem dos kits e gasta lutando. |
| Classe | A especialização de combate do personagem (ex.: Paladino). Define skills e perks. |
| COMÉRCIO | Sistema planejado de estabelecimentos administrados por jogadores, com contratação de profissionais e tributação própria. |
| Conjuração | Magia que pode chamar uma criatura para ajudar o personagem. |
| Diademas | Saldo adquirido com dinheiro real e usado na Loja. |
| Disciplina (vampiro) | Especialidade que o vampiro escolhe no design das maldições (ex.: Fortitude). |
| Dungeon | Área com inimigos e recompensas, que "renasce" depois de um tempo. |
| Fadiga (de XP) | Limite de XP por dia a partir do nível 15. Recomeça às 06:00. |
| Geração (de masmorra) | A "leva" de inimigos de uma masmorra, igual para todos até o reset. |
| Imposto de Comércio | Tributo mensal planejado para estabelecimentos; definido pelo Rei da jurisdição, com cálculo e calendário ainda pendentes. |
| Instância | Uma versão separada de uma área, usada para manter certos jogadores ou atividades no mesmo ambiente. |
| IPTU | Imposto periódico da residência, cobrado em Septims. |
| Kit de manutenção | Item que dá 50 cargas de manutenção de um material. |
| Maldição | Vampirismo, licantropia ou bruxaria: condição recebida por RP, com estágios próprios. Planejada. |
| Marco | Nível de classe que dá recompensa: 1, 5, 10, 15, 20, 25, 30, 35 e 40. |
| Nível de combate | Força de um inimigo, de 1 a 100. Quanto maior, mais XP. |
| Pedra guardiã | Pedra escolhida pelo jogador que dá um bônus permanente (ex.: Pedra do Guerreiro, +50 de vida). |
| Perk | Talento do Skyrim que melhora o personagem (ex.: mais dano com espada). |
| Pontos de atributo | 15 por nível, para aumentar vida, magia ou vigor. |
| PD | Perda definitiva de personagem. |
| Raid | Grupo grande, de 8 a 20 jogadores. |
| Raça | Povo do personagem (Nórdico, Khajiit...). Cada uma tem uma habilidade fixa. |
| Respawn | Quando inimigos ou itens reaparecem depois de derrotados ou coletados. |
| Setagem | Quando a Staff aplica algo ao personagem pelo painel (ex.: classe de Winterhold, maldição). |
| Septims | Moeda do jogo. |
| Skill | Habilidade do Skyrim (ex.: Uma Mão, Destruição). Na classe, o valor é definido pelo servidor. |
| RP (roleplay) | Interpretar o personagem como se fosse real, dentro da história do servidor. |
| Vertente (bruxaria) | Linha que o bruxo escolhe no design: Mortui, Daemones ou Tenebrae. |
