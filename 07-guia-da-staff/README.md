# Guia da Staff

Explicações **simples e didáticas** de como o Aetherius funciona, para toda a Staff (moderação, suporte, eventos, lore), não só para devs.

> Não sabe um termo? Veja o [glossário](glossario.md). Precisa do detalhe técnico? Cada guia tem um link para a versão técnica em `02-sistemas/`.

## 📊 [Progresso do desenvolvimento](progresso.md)
Situação atual de cada sistema, atualizada a cada mudança.

## Temas

| Tema | Do que trata |
|---|---|
| [`classes/`](classes/README.md) | Classes disponíveis, o que cada uma faz e como evoluir nelas. |
| [`racas-e-pedras/`](racas-e-pedras/README.md) | Bônus de cada raça e de cada pedra guardiã. |
| [`progressao/`](progressao/README.md) | Níveis, estágios de progressão e como o jogador avança. |
| [`dungeons/`](dungeons/README.md) | Dungeons, dificuldade, recompensas e tempo de respawn. |
| [`sobrenatural/`](sobrenatural/README.md) | Vampirismo, licantropia e outras condições sobrenaturais. |
| [`profissoes/`](profissoes/README.md) | Profissões, como aprender, evoluir e o que produzem. |
| [`itens/`](itens/README.md) | Catálogo de itens: onde obter, para que servem e raridade. |
| [`economia/`](economia/README.md) | Moeda, preços, comércio entre jogadores e lojas. |
| [`regras-de-roleplay/`](regras-de-roleplay/README.md) | Regras de RP do servidor e como a Staff deve aplicá-las. |
| [Guildas](regras-de-roleplay/guildas.md) | Magos, Alquimistas e Companions, em desenvolvimento por Melekyy. |
| [`perguntas-frequentes/`](perguntas-frequentes/README.md) | Dúvidas comuns de jogadores e as respostas oficiais. |

Novos temas são bem-vindos: crie uma subpasta e use o modelo [`_modelos/GUIA-STAFF.md`](../_modelos/GUIA-STAFF.md).
